# Information architecture

## Card sorting rationale

Services are grouped by how an industrial buyer frames a need: **Source** (procurement), **Engineer** (mechanical design), **Deliver** (project management), and **Make** (custom fabrication). This makes a technical capability easy to scan without mixing commercial and operational decisions.

## Top-level navigation

- Home
- Profile
- Capabilities (multi-level: Source, Engineer, Deliver, Make)
- Work
- Partners
- Contact / Request Quote

## Interaction-state coverage

Buttons define default, hover, active, and disabled states. Navigation declares selected and expanded states. Quote form fields define focus and validation behavior. The technical table covers hover/focus context and the service menu covers expanded/collapsed state.
